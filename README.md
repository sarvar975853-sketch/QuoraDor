# QuoraDor

A native cross-platform Quoridor board game built with HTML and Tauri.

## Features

- Classic Quoridor gameplay
- Human vs Human
- Human vs AI
- Smooth animations
- Native macOS application
- Windows application
- Web version

## Downloads

Go to the [Releases](../../releases) page to download the latest version.

### macOS

Download:

`QuoraDor-macOS.zip`

Extract it and open `QuoraDor.app`.

### Windows

Download:

`QuoraDor-Windows-x64.exe`

Run the installer to install QuoraDor.

## Web Version

The web version is available through [GitHub Pages.](https://sarvar975853-sketch.github.io/QuoraDor/)
